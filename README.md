## Установка
Не забудьте скачать все необходимые утилиты (в основном из .config)

### С помощью GNU Stow
```bash
# В домашней директории
git clone https://github.com/ArsExample/dotfiles.git
cd dotfiles
stow .
```

### Ручная установка
```bash
git clone https://github.com/ArsExample/dotfiles.git
```
И вручную копируйте файлы из dotfiles в нужное место
